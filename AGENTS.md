# AGENTS.md — Project Governance & Content Standards

## 1. Strictly Prohibited Words & Assurances (Blacklist)

The following words and expressions are strictly prohibited across all AI narrative generation, UI copy, system prompts, badges, buttons, tooltips, and documentation:

1. **"Guarantee" / "Guaranteed" / "Guarantees"**:
   - **Banned:** "100% Genesis LP Burn Guarantee", "Guaranteed 100x", "Security Guarantee", "Non-inflationary supply guarantee", "Guaranteed profit".
   - **Approved Replacements:** State facts objectively without marketing promises. Use "100% Genesis LP Token Burn", "Permanent Revocation", "On-Chain Parameter", "Security Architecture", or "Verification Specification".

2. **"1000%" / "+1000%" / Ungrounded Pump Numbers**:
   - **Banned:** "+1000%", "1000% Genesis Burn", "+500% Pump", "100x Moon".
   - **Approved Replacements:** "Fair Launch", "100% Community Distribution", or "Bonding Curve Progress". Lore must be humorous and meme-native, never citing fabricated percentage returns or speculative price pumps.

3. **"Raid" / "Raider" / "Raids"**:
   - **Banned:** "Twitter Raid", "Execute Raid", "Community Raid Call", "Raider Bot".
   - **Approved Replacements:** "Community Mobilization", "Social Rally", "Community Dispatch", "Broadcast", "Viral Amplify".

4. **"Audit" / "Audited" / "Auditor"** (for internal/automated checks):
   - **Banned:** "Smart Contract Audit", "Audited by Agent 0", "Audit Guarantee", "Audit Certification".
   - **Approved Replacements:** "Pre-Flight Verification", "Parameter Inspection", "Heuristic Review", "Static Bytecode Check", "Adversarial Screening". (Reserve the word "audit" strictly for disclaimers clarifying that the tool is *not* a third-party audit firm).

## 2. Dynamic Agent Generation Rules

- **Agent 1 (Narrative Strategist):**
  - Keep narrative lore entertaining, absurd, or satirical.
  - Zero financial promises, zero fake exchange listings, and zero ungrounded percentage claims.
  - Never include blacklisted words (`guarantee`, `1000%`, `raid`, `audit`).

- **Agent 2 (Visual Studio):**
  - Do not place fake percentage claims (`+1000%`, `100x`) or `GUARANTEED` badges on meme canvases.
  - Keep canvas overlays centered on cultural satire, breaking news parodies, or chart memes without financial solicitation.

- **Agent 3 (Community Mobilizer & Dispatch):**
  - Formats community social dispatches, milestone celebrations, and Telegram alerts.
  - Use terms like "⚡ Execute Community Broadcast", "Mobilize the Feed", or "Share Mascot Art". Never use "Raid".

- **Agent 0 (Pre-Flight Scanner & Adversarial Check):**
  - Operates as a local heuristic validator and sanitizer.
  - Automatically scrubs blacklisted terms before content is displayed to the user.
